How do I describe a shared error?

A common ruler offset of 0.2 cm uses {"name":"Ruler offset","unit":"cm","sigma":0.2,"weights":{"a":1,"b":1}} inside a list. A positive weight moves a reading with the error; a negative weight moves it against the error. Use the same dimensions as the affected readings. Each source is independent of every other source.

Formula and unit guide

Use +, − (type a hyphen), *, /, ^, parentheses, pi, sqrt, sin, cos, exp and log. Powers must be constant integers from −12 to 12. Trig/log/exp arguments must be dimensionless. Units: 1, m, cm, mm, kg, g, s, ms, min, A, K, mol, cd, Hz, N, J, Pa, W, V, ohm. Join with * or /; powers use ^. No implicit multiplication, affine temperatures or unit parentheses.
